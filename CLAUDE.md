# Workflow

For every multi-step task:

1. First understand my full request before changing code.
2. Inspect the relevant existing files.
3. Create a short and clear TODO checklist.
4. Work through the TODO items one by one.
5. Mark each item `[x]` as soon as it is actually completed.
6. If new necessary work is discovered, add it to the TODO list.
7. Do not make unrelated changes.
8. After implementation, run appropriate build, type-check, lint, or tests when available.
9. Fix issues found during verification.
10. Finish with a short summary of what changed and any remaining issues.

For very small/simple tasks, do not create unnecessary TODO lists or task files.

For larger multi-step tasks, create or maintain a `TASKS.md` file in the project root with:

* Current goal
* TODO checklist
* Completed items `[x]`
* Remaining items `[ ]`
* Important notes only when needed

Keep the workflow concise to avoid unnecessary token usage.
